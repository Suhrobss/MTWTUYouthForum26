# MTWTU Youth Forum 2026 · Плай

Сайт-компаньйон форуму Молодіжної ради ПРМТУ (7–10 грудня 2026, ГК «Плай»).
Нова версія з тими ж розділами й контентом, але з іншим дизайном і функціями, яких раніше не було.

## Концепція дизайну

**Карпатська топографія × ски-пас.** Сніжний папір, графітовий текст, помаранчевий як у підйомників.

- **Генеративна топокарта** на головній: живі ізолінії, які реагують на курсор.
- **Ски-пас** замість звичайної обкладинки: фото форуму на картці, що нахиляється за курсором і переливається голограмою.
- **Чотири дні = чотири траси**: зелена, синя, червона, чорна. У кожної ще й своя форма (●■◆◆◆), тож дні розрізняються навіть без кольору.
- **Профіль дня**: силует гір, де висота піку показує вагу події. Пунктирна лінія позначає, котра зараз година.
- Світла й темна тема, адаптив від 320 px, PWA та офлайн-режим.

## Що нового

| Функція | Опис |
|---|---|
| **Запитай Claude** | Консьєрж на базі Claude (Anthropic), що відповідає лише з програми, оголошень і логістики. Нічого не вигадує й прямо каже, коли щось ще не підтверджено. Відповіді йдуть потоком (streaming), а згадані події перетворюються на картки. Якщо ключа немає, працює локальний пошук по програмі. |
| **Мій маршрут** | ★ на будь-якій афіші додає подію до особистої програми. Сайт попереджає про накладки паралельних сесій і дає експорт у календар (.ics). |
| **Зараз / Далі** | Живий блок за київським часом і зворотний відлік до старту. |
| **Календар** | Можна додати одну подію або весь день одним файлом. |

## Запуск

```bash
npm install
ADMIN_PASSWORD=secret npm start   # http://localhost:3000
```

## Деплой на Railway

1. Створіть новий репозиторій на GitHub і запуште цей код (див. нижче).
2. Railway → New Project → Deploy from GitHub repo. Node визначиться автоматично (`npm start`).
3. Додайте **Volume**, змонтуйте в `/data` і задайте `DATA_DIR=/data`, щоб оголошення, правки й підписки переживали редеплой.
4. Змінні середовища:

| Змінна | Обов’язково | Опис |
|---|---|---|
| `ADMIN_PASSWORD` | так | Пароль панелі організатора (`/#/admin`) |
| `SESSION_SECRET` | бажано | Довгий випадковий рядок, щоб сесії не скидалися після рестарту |
| `DATA_DIR` | бажано | Шлях до volume, напр. `/data` |
| `ANTHROPIC_API_KEY` | для AI | Ключ з console.anthropic.com. Без нього працює локальний пошук |
| `ANTHROPIC_MODEL` | ні | За замовчуванням `claude-sonnet-4-5` |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | ні | Якщо не задати, ключі згенеруються й збережуться у сховищі |
| `SITE_MODE` | ні | `preview` (показує плашку «Робочий макет») або `live` |

## Структура

```
server.js            HTTP-сервер без фреймворків: API, адмінка, push, Claude (SSE)
data/program.json    Початкові дані: 31 подія з анонсами з оригінального сайту
public/index.html    Оболонка
public/app.js        SPA на чистому JS (hash-маршрутизація)
public/styles.css    Дизайн-система
public/sw.js         Офлайн + push
```

## Безпека та чесність даних

- Claude отримує лише опубліковані дані. Системний промпт забороняє вигадувати час, місця, імена, контакти й безпекові інструкції.
- Питання про укриття та тривоги Claude перенаправляє до офіційних вказівок організаторів.
- Вхід в адмінку обмежено за кількістю спроб, сесія тримається в HttpOnly + SameSite cookie, діють CSP та обмеження на кількість запитів до AI.
